NMRExampleData — Module

Example NMR data shared by NMRTools.jl, NMRAnalysis.jl and NMRScreen.jl.

Each example is a folder under datasets/ with a dataset.toml. Released examples are downloaded the first time they are used, and only then.

NMRExampleData.exampleinfo — Function
exampleinfo(name) -> NamedTuple

The description of an example dataset, from its dataset.toml: name, title, spectrum, description, credit (a vector of "Name <email>" or "Name"), citation, licence, source, aliases and added. Nothing is downloaded.

name may be the dataset's full name or an alias, in any case, or the start of the name or of any part of it between underscores: "hetnoe" finds "hetnoe2d_calr", and the old NMRTools name "2D_HN" finds "2d_hn_ubq". Where that matches several datasets, the one added first is used, so a shortened name keeps meaning the same dataset as more are added. The full name is returned as name.

Example

julia> exampleinfo("hetnoe2d_calr").title
"CALR 2D 1H,15N hetNOE (600 MHz, 298 K)"

NMRExampleData.examplepath — Function
examplepath(name; fid=false) -> String or Vector{String}

The path of the experiment to load from an example dataset, as given by spectrum in its dataset.toml. Where spectrum lists several experiments (a titration, a hetNOE pair, a relaxation series) this is a vector of paths in that order. Where spectrum is empty, the dataset's folder. Downloads the dataset the first time it is used; see exampledir.

Example

julia> using NMRTools
julia> spec = loadnmr.(examplepath("relaxation2d_ubq"))

NMRExampleData.exampledir — Function
exampledir(name; fid=false) -> String

The folder holding the whole of an example dataset: every experiment in it, any sample record, and any analysis/ folder. Downloads the dataset the first time it is used.

The download leaves out the raw time-domain data (fid and ser files) unless fid=true. In a clone of this repository with the data fetched from Git LFS, the dataset's own folder is used instead and nothing is downloaded.

Example

julia> dir = exampledir("hetnoe2d_calr")
julia> readdir(dir)
