NMRExampleData — Module

Example NMR data shared by NMRTools.jl, NMRAnalysis.jl and NMRScreen.jl.

Each example is a folder under datasets/ with a dataset.toml. Released examples are downloaded the first time they are used, and only then. The registered package holds no datasets, only Datasets.toml, the index of their dataset.toml files.

NMRExampleData.examples — Function
examples() -> Vector{String}

Names of the available example datasets, in alphabetical order: all of them, or those holding data in format (see FORMATS), such as :ucsf.

Example

 "relaxation2d_ubq"

NMRExampleData.exampleinfo — Function
exampleinfo(name) -> NamedTuple

The description of an example dataset, from its dataset.toml: name, title, path, formats, description, credit (a vector of "Name <email>" or "Name"), citation, licence, source, aliases and added. Nothing is downloaded.

formats names the files holding each format of the data, relative to the dataset's folder, with the default (path) first: (bruker = "1", nmrpipe = "1/test.ft2").

name may be the dataset's full name or an alias, in any case, or the start of the name or of any part of it between underscores: "hetnoe" finds "hetnoe2d_calr". Where that matches several datasets, the one added first is used, so a shortened name keeps meaning the same dataset as more are added. The full name is returned as name.

Example

julia> exampleinfo("hetnoe2d_calr").title
"CALR 2D 1H,15N hetNOE (600 MHz, 298 K)"

NMRExampleData.example — Function
example(name)
example(name, format)
example()

What an example dataset is opened with, downloading it the first time it is used: the path given by path in its dataset.toml, with the same shape. Given a format, such as :nmrpipe or :ucsf, the same data in that format instead, where the dataset has it. That is an experiment folder or file, a vector of them for a series, nested vectors where an analysis takes its data in roles, or the experiment.toml of a screen. Where path is empty, the dataset's folder.

The first time a dataset is used in a session, who to credit, what to cite and the licence are shown.

Without a name, choose a dataset from a menu, or outside an interactive session, list them.

See exampleinfo for how names are matched, and exampleanalysis for a dataset's saved analysis.

Examples

julia> using NMRTools

julia> spec = loadnmr(example("2d_hn_ubq"))          # a spectrum, or a vector of them
julia> fid = loadfid(example("2d_hn_ubq"))           # its raw data
julia> spec = loadnmr(example("2d_hn_ubq", :ucsf))   # the same spectrum, from UCSF
julia> reference, saturated = example("hetnoe2d_calr")
julia> screen(example("screen_bsa"))                  # with NMRScreen

NMRExampleData.exampleanalysis — Function
exampleanalysis(name) -> String

The saved analysis of an example dataset: an output folder written by NMRAnalysis, with the picked peaks in peaklist.csv, the results, and the record that reopen reads. Downloads the dataset the first time it is used. Throws an ArgumentError for a dataset without one.

Examples

julia> using NMRAnalysis

julia> expt = reopen(exampleanalysis("relaxation2d_ubq"))   # as saved, ready to refit
julia> pks = loadpeaks(exampleanalysis("relaxation2d_ubq"))  # just the peaks

NMRExampleData.FORMATS — Constant
FORMATS

The formats a dataset may hold, in the order exampleinfo lists them: Bruker experiment folders, nmrPipe and UCSF (Sparky) spectra, NMR-STAR shift lists from the BMRB, and the experiment.toml of an NMRScreen screen.
