NMRExampleData.jl

Example NMR data for NMRTools.jl, NMRAnalysis.jl and NMRScreen.jl: real spectra, with their raw data, sample records and analyses, for tutorials, documentation and tests. The Catalogue lists every dataset.

Installing the package downloads no data. Each dataset is downloaded the first time you use it, and only that one.

Opening a dataset

example(name) gives what a dataset is opened with, downloading it the first time: a spectrum, a vector of them for a series, or the experiment.toml of a screen. You open it with the package it is for:

using NMRTools

spec = loadnmr(example("titration2d_fir_nbox"))   # NMRData, or a vector of them for a series
fid = loadfid(example("titration2d_fir_nbox"))    # the raw data
example()                                         # choose a dataset from a menu

With NMRAnalysis, start an analysis from a dataset's spectra, or reopen the analysis saved with it, with its peaks picked and its parameters set:

using NMRAnalysis

expt = relaxation2d(example("relaxation2d_ubq"))     # from the start
expt = reopen(exampleanalysis("relaxation2d_ubq"))   # as saved, ready to refit

Where an analysis takes its data in roles, example returns them in that order, to unpack:

reference, saturated = example("hetnoe2d_calr")
expt = hetnoe2d(reference, saturated)

With NMRScreen, a screen opens from its experiment.toml. NMRTools and NMRAnalysis make these functions available; with NMRScreen, load NMRExampleData as well:

using NMRScreen, NMRExampleData

screen(example("screen_bsa"))

The first time a dataset is used in a session, who to credit, what to cite and the licence are shown. exampleinfo gives the same information at any time, and examples() lists every dataset.

Other formats

Some datasets hold the same experiment in other formats too, as nmrPipe or UCSF (Sparky) spectra beside the Bruker data. example gives the Bruker data unless asked for another format, and exampleinfo says which formats there are, and which files hold them:

loadnmr(example("3d_hnca_ubq"))             # the Bruker experiment
loadnmr(example("3d_hnca_ubq", :nmrpipe))   # the same spectrum, from nmrPipe
exampleinfo("3d_hnca_ubq").formats          # (bruker = "1", nmrpipe = "1/smile/test%03d.ft3", …)
examples(:ucsf)                             # every dataset with UCSF data

So a test of a file format can run over every dataset that has it:

for name in examples(:ucsf)
    @test loadnmr(example(name, :ucsf)) isa NMRData
end

Shortened names

Names ignore case, and can be shortened to the start of the full name or of any part of it: "titration2d" and "fir" both find titration2d_fir_nbox. Where a shortened name matches several datasets, the one added first is used, so it keeps meaning the same dataset as more are added. In code that others will run, give the full name.

Versions

Each version of the package points at a fixed set of data, so results stay reproducible. Depend on it as NMRExampleData = "1" to get new data with ordinary package updates; see Releases for how versions are numbered.

Credit and licences

Each dataset gives who to credit, a paper to cite where there is one, and the licence it is shared under, usually CC BY 4.0. A licence of "None" means that no licence has been granted: ask the people credited before using those data beyond trying out the software. The code is released under the MIT licence.

To share your own data, see Adding data.

The ecosystem

  • NMRTools.jl: loading, processing, plotting and peak picking of NMR data, with pulse programme annotations and sample records.
  • NMRAnalysis.jl: interactive analysis of relaxation, titration, diffusion and other series of spectra.
  • NMRScreen.jl: analysis of NMR screens.
  • MulticomplexNumbers.jl: the algebra NMRTools uses for multidimensional quadrature data.
  • The Waudby lab at the UCL School of Pharmacy.
